Project Overview

Music has hidden layers

Strata takes any song, separates it into its four instrument stems using AI, analyzes each stem musically, and drives a cinematic 3D scene — all in real time in the browser.

Feature Extraction

6 Features · 4 Stems · 60 FPS

Feature Range What it captures Used by
rms0 – 1Volume / energy level (normalized)All layers
onset0 – 1Attack sharpness — how sudden a sound hitsDrums, beat pulse
spectral_centroidHzBrightness — where frequency mass is centeredMelody ribbon color
chroma12 × [0,1]Per-semitone pitch energy (one entry per note)Melody pitch, harmonic cloud
pitch_hzHzDominant pitch detected via YIN algorithmMelody ribbon height
beat_phase0 – 1Position within the current beat cycleCamera punch, bloom

Architecture

Tech Stack

🐍
Python Backend
Demucs (htdemucs) — Meta AI source separation model

librosa — audio feature extraction (RMS, onset, chroma, pitch, beat)

NumPy — fast array math

Outputs a single features.json that drives the entire frontend
⚡
JavaScript Frontend
Three.js — WebGL 3D scene, 4 custom visualizers, post-processing

Vite — fast HMR dev server, optimized static build

lil-gui — debug panel (press G), layer toggles, video recorder

GitHub Pages — zero-server static hosting, instant deploy
No backend at runtime Pure browser WebGL 60 fps target Built-in video recorder Click-to-seek progress bar
